# 示例配置文件

本目录包含旧版配置文件作为参考示例。

## 文件说明

### `train_legacy.yaml`
- 旧版标准训练配置（手动阶段管理）
- 已被 `train/train_default.yaml` 替代
- 保留作为配置参考

### `train_walking_legacy.yaml`
- 旧版行走任务配置（手动阶段管理）

- 包含详细的显存和性能注释

## 迁移说明

从 2026-01-05 起，项目采用自动课程学习框架，无需手动配置阶段。

**旧方式**（已弃用）：
- 手动配置多个阶段文件（stage0/1/2*.yaml）
- 手动切换配置文件训练不同阶段
- 需要人工干预阶段转换

**新方式**（推荐）：
- 单个配置文件完成全程训练
- 自动三阶段课程学习（站立→低速→全速）
- 奖励权重和环境参数自动切换

详细说明请参考：[../README.md](../README.md)
